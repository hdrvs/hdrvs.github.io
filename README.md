# The HDR Videographic Survey
Future home of the HDR Videographic Survey dataset.

Contact tcanham at yorku dot ca for early access

Subset used in [**Adaptive Color Grading**](https://arxiv.org/abs/2609.21169) available on [Hugging Face](https://huggingface.co/datasets/trevorcanham/hdrvs_adaCGsubset).

Subset used in [**A Unified Framework for High-Frame-Rate HDR Video Synthesis**](https://bmvc2025.bmva.org/proceedings/824/) available on [Hugging Face](https://huggingface.co/datasets/huent189/unified-HFR-HDR)
